# Daybreak — Job board

A responsive React job board frontend designed for job seekers. It includes role search and filters, saved jobs, a career assistant chat widget, and a WhatsApp support shortcut.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Job listings and assistant answers currently use sample data in the frontend. Replace the sample listings in `src/App.jsx` and connect a jobs API and application URLs when those are available.
